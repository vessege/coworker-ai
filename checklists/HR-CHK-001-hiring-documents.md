# 🇺🇿 Ishga qabul — huquqiy tekshiruv checklisti

## Shartnomadan oldin
- [ ] Lavozim shtat jadvalida mavjud va bo'sh
- [ ] Nomzod hujjatlari: pasport/ID, ma'lumot (talab qilinsa), mehnat daftarchasi
- [ ] Qonunda yo'q hujjat talab qilinmagan
- [ ] Yosh/toifa cheklovlari tekshirildi (voyaga yetmagan, homilador va h.k. — maxsus qoidalar)

## Shartnoma
- [ ] Yozma shaklda, **2 nusxa**
- [ ] Lavozim, ish haqi, ish vaqti, ish joyi aniq yozilgan
- [ ] Sinov muddati ≤ 3 oy (rahbar/bosh buxgalter ≤ 6 oy) va shartnomada yozilgan
- [ ] Xodim ish boshlashdan **oldin** imzolagan, bir nusxani olgan

## Rasmiylashtirish
- [ ] Ishga qabul buyrug'i chiqarilgan (HR-TPL-001), shartnomaga mos
- [ ] Xodim buyruq bilan imzo qo'yib tanishgan
- [ ] Kadrlar hisobi / elektron mehnat daftarchasiga yozilgan
- [ ] Ichki mehnat tartib-qoidalari bilan tanishtirilgan
- [ ] Mehnat muhofazasi bo'yicha yo'riqnoma o'tkazilgan

## Keyin
- [ ] Onboarding boshlangan (OM-CHK-001)
- [ ] Ish haqi hisobiga qo'shilgan (buxgalteriya xabardor)

# 🇬🇧 Hiring — Compliance Checklist

## Before the contract
- [ ] Position exists in the staffing table and is vacant
- [ ] Candidate documents: passport/ID, diploma (if required), employment history
- [ ] No documents requested beyond what the law allows
- [ ] Age/category restrictions checked (minors, pregnancy etc. — special rules)

## Contract
- [ ] Written form, **2 copies**
- [ ] Position, pay, working time, workplace stated explicitly
- [ ] Probation ≤ 3 months (heads/chief accountant ≤ 6) and written in the contract
- [ ] Signed **before** work starts; employee keeps one copy

## Formalization
- [ ] Hiring order issued (HR-TPL-001), matching the contract
- [ ] Employee acknowledged the order by signature
- [ ] Entered into personnel records / electronic labour book
- [ ] Introduced to internal labour regulations
- [ ] Occupational safety briefing done

## After
- [ ] Onboarding started (OM-CHK-001)
- [ ] Added to payroll (accounting notified)
