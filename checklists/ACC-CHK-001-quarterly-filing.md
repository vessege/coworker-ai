# 🇺🇿 Choraklik soliq hisoboti — checklist

## Chorak yopilishidan oldin (oxirgi hafta)
- [ ] Barcha EHF (kiruvchi/chiquvchi) tizimda tasdiqlangan
- [ ] Aktlar imzolangan va fakturalarga mos
- [ ] Bank ko'chirmalari to'liq, kassa qoldiqlari solishtirilgan
- [ ] Aylanma (tushum) summasi hisoblangan va chegara bilan taqqoslangan (1 mlrd — YaTT)

## Hisobot tayyorlash
- [ ] Aylanma soliq hisoboti shaxsiy kabinetda (my.soliq.uz) to'ldirilgan
- [ ] Stavka to'g'ri: yuridik shaxs 4% (bazaviy), YaTT 1% (ACC-KA-003)
- [ ] Summalar birlamchi hujjatlar bilan mos (ACC-BR-001/BR-8)
- [ ] Bosh buxgalter/rahbar tekshirdi

## Topshirish va to'lash
- [ ] Hisobot ERI bilan yuborilgan, qabul kvitansiyasi saqlangan
- [ ] Soliq to'langan, to'lov topshirig'i arxivda
- [ ] Muddat o'tmagan (kechiksa — ACC-KA-004: penya/jarima)

## Yopilgandan keyin
- [ ] Hujjatlar arxivlangan (chorak papkasi)
- [ ] Kelgusi chorak muddatlariga eslatma qo'yilgan

# 🇬🇧 Quarterly Tax Filing — Checklist

## Before quarter close (last week)
- [ ] All e-invoices (in/out) confirmed in the system
- [ ] Acts signed and matching invoices
- [ ] Bank statements complete, cash reconciled
- [ ] Turnover computed and compared to the threshold (1 bln — sole proprietor)

## Preparing the report
- [ ] Turnover-tax report filled in the personal cabinet (my.soliq.uz)
- [ ] Correct rate: legal entity 4% (base), sole proprietor 1% (ACC-KA-003)
- [ ] Amounts match primary documents (ACC-BR-001/BR-8)
- [ ] Reviewed by chief accountant/head

## Filing and paying
- [ ] Report submitted with e-signature; receipt saved
- [ ] Tax paid; payment order archived
- [ ] Deadline met (late → ACC-KA-004: penalty interest/fine)

## After close
- [ ] Documents archived (quarter folder)
- [ ] Reminders set for next quarter's deadlines
