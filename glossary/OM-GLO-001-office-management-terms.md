# 🇺🇿 Ish yuritish va ofis boshqaruvi lug'ati

| Atama | Ta'rif |
|-------|--------|
| **Ish yuritish (delovodstvo)** | Hujjatlarni yaratish, ro'yxatga olish, aylanishi, saqlash va arxivlash bo'yicha faoliyat. |
| **Rekvizit** | Hujjatning ajralmas elementi (sana, raqam, imzo, muhr va h.k.). |
| **Hujjat aylanishi** | Hujjatning yaratilgan yoki qabul qilingan paytdan ijro/saqlashgacha bo'lgan harakati. |
| **Kiruvchi hujjat** | Tashkilotga tashqaridan kelgan hujjat. |
| **Chiquvchi hujjat** | Tashkilot tomonidan tashqariga jo'natiladigan hujjat. |
| **Ichki hujjat** | Tashkilot ichida yaratilib, ichida ishlatiladigan hujjat. |
| **Rezolyutsiya** | Rahbarning hujjatga qo'ygan topshirig'i: ijrochi va muddat. |
| **Nomenklatura** | Tashkilot ishlari (papkalar)ning tizimlashtirilgan ro'yxati va saqlash muddatlari. |
| **Ish indeksi** | Nomenklatura bo'yicha ishga berilgan shartli raqam. |
| **Blank** | Rekvizitlari oldindan bosilgan rasmiy qog'oz. |
| **Ijro nazorati** | Hujjat topshiriqlari muddatida bajarilishini kuzatish. |
| **Arxiv** | Ijro etilgan hujjatlar belgilangan muddat saqlanadigan joy. |
| **EHAT** | Elektron hujjat aylanishi tizimi. |
| **Farmoyish hujjati** | Buyruq, farmoyish, qaror kabi boshqaruv qarorini rasmiylashtiruvchi hujjat. |
| **Tashkiliy hujjat** | Nizom, ustav, shtat jadvali, lavozim yo'riqnomasi kabi hujjatlar. |
| **Ma'lumot-ma'lumotnoma hujjati** | Xat, dalolatnoma (akt), ma'lumotnoma, xizmat xati. |
| **Muhr (M.O'.)** | Hujjatning haqiqiyligini tasdiqlovchi bosma; "M.O'." — muhr o'rni. |

# 🇬🇧 Office Management & Record-Keeping Glossary

| Term | Definition |
|------|------------|
| **Record-keeping (delovodstvo)** | Activity of creating, registering, circulating, storing and archiving documents. |
| **Requisite** | An essential element of a document (date, number, signature, seal, etc.). |
| **Document flow (circulation)** | Movement of a document from creation/receipt to execution/storage. |
| **Incoming document** | A document received by the organization from outside. |
| **Outgoing document** | A document sent by the organization to outside parties. |
| **Internal document** | A document created and used within the organization. |
| **Resolution** | The manager's instruction on a document: assignee and deadline. |
| **Nomenclature of files** | Systematized list of the organization's cases (folders) with retention periods. |
| **Case index** | The conditional number assigned to a case per the nomenclature. |
| **Letterhead (blank)** | Official paper pre-printed with requisites. |
| **Execution control** | Monitoring that document tasks are completed on time. |
| **Archive** | Where executed documents are stored for the prescribed period. |
| **EDMS** | Electronic Document Management System. |
| **Administrative (order) document** | Document formalizing a management decision: order, directive, resolution. |
| **Organizational document** | Documents such as charter, statute, staffing table, job description. |
| **Information-reference document** | Letter, act, reference/certificate, service note. |
| **Seal** | Imprint confirming a document's authenticity; "M.O'." marks the seal location. |
