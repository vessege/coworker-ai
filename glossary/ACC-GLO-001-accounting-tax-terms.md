# 🇺🇿 Buxgalteriya va soliq atamalari

| Atama | Ta'rif |
|-------|--------|
| **QQS** | Qo'shilgan qiymat solig'i (rus. НДС). Bazaviy stavka 12%. |
| **Aylanmadan olinadigan soliq** | Soddalashtirilgan rejim solig'i, aylanma (tushum)dan olinadi. |
| **Foyda solig'i** | Yuridik shaxs foydasidan olinadigan soliq (bazaviy 15%). |
| **Ijtimoiy soliq** | Ish haqi/faoliyatdan ijtimoiy fondlarga to'lov. |
| **BHM** | Bazaviy hisoblash miqdori — jarima/to'lovlar hisoblanadigan asos. |
| **STIR** | Soliq to'lovchining identifikatsiya raqami (rus. ИНН). |
| **MXIK (IKPU)** | Mahsulot va xizmatlarning identifikatsiya kodi. |
| **EHF** | Elektron hisobvaraq-faktura. |
| **ERI** | Elektron raqamli imzo. |
| **Penya** | Soliqni kechiktirib to'laganlik uchun har kunlik hisoblanadigan summa. |
| **Jarima** | Hisobotni kechiktirish/qoidabuzarlik uchun belgilangan summa. |
| **YaTT** | Yakka tartibdagi tadbirkor. |
| **MChJ (OOO)** | Mas'uliyati cheklangan jamiyat. |
| **Umumiy rejim** | QQS va foyda solig'i to'lanadigan soliq rejimi. |
| **Shaxsiy kabinet** | my.soliq.uz dagi soliq to'lovchi elektron kabineti. |
| **Birlamchi hujjat** | Xo'jalik operatsiyasini tasdiqlovchi hujjat (faktura, akt, nakladnaya). |
| **h/r** | Hisob raqami (bank). |
| **MFO** | Bank identifikatsiya kodi. |

# 🇬🇧 Accounting & Tax Terms

| Term | Definition |
|------|------------|
| **VAT (QQS)** | Value-added tax (rus. НДС). Base rate 12%. |
| **Turnover tax** | Simplified-regime tax levied on turnover (revenue). |
| **Profit tax** | Tax on a legal entity's profit (base 15%). |
| **Social tax** | Payment on wages/activity to social funds. |
| **BHM** | Base calculation amount — the base for fines/payments. |
| **STIR** | Taxpayer identification number (rus. ИНН). |
| **IKPU (MXIK)** | Identification code of goods and services. |
| **EHF** | Electronic invoice. |
| **ERI** | Electronic digital signature. |
| **Penya** | Daily-accrued amount for late tax payment. |
| **Jarima (fine)** | Set amount for late filing / violation. |
| **YaTT** | Sole proprietor (individual entrepreneur). |
| **MChJ (OOO)** | Limited liability company. |
| **General regime** | Tax regime with VAT and profit tax. |
| **Personal cabinet** | Taxpayer's e-cabinet on my.soliq.uz. |
| **Primary document** | Document confirming a business operation (invoice, act, waybill). |
| **h/r** | Bank account number. |
| **MFO** | Bank identification code. |
