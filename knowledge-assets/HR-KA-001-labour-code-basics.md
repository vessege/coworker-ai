# 🇺🇿 Mehnat kodeksi 2023 — asosiy qoidalar

Yangi Mehnat kodeksi **2023-yil 30-apreldan** kuchda (7 bo'lim, 34 bob, 581 modda).

| Mavzu | Qoida |
|-------|-------|
| **Mehnat shartnomasi** | Yozma shaklda, kamida **2 nusxada**, har bir tomonga beriladi |
| **Sinov muddati** | Ko'pi bilan **3 oy**; rahbar, o'rinbosar va bosh buxgalter uchun **6 oygacha**. Kasallik/uzrli sabab kunlari sinovga kirmaydi |
| **Yillik ta'til** | Kamida **21 kalendar kun** (217-modda). Endi ish kunida emas, **kalendar kunda** hisoblanadi |
| **Qo'shimcha ta'til (staj)** | Bitta tashkilotda har **5 yil** uchun **+2 kun**, jami ko'pi bilan **+8 kun** (220-modda) |
| **Dam olish** | Haftalik dam olish kunlari, bayramlar, yillik haq to'lanadigan ta'til kafolatlanadi |
| **Ish vaqti** | Cheklangan; ayrim toifalarga qisqartirilgan ish vaqti |

## KO'B uchun amaliy xulosalar
- Og'zaki ishga olish mumkin emas — shartnoma yozma bo'lishi shart.
- Sinov muddatini shartnomada aniq yozing; 3 oydan oshirmang.
- Ta'til jadvalini yil boshida tuzing; 21 kundan kam ta'til berish qonunbuzarlik.

# 🇬🇧 Labour Code 2023 — Key Rules

The new Labour Code is in force since **April 30, 2023** (7 sections, 34 chapters, 581 articles).

| Topic | Rule |
|-------|------|
| **Employment contract** | Written form, at least **2 copies**, one for each party |
| **Probation** | Max **3 months**; up to **6 months** for heads, deputies, chief accountants. Sick/excused days don't count |
| **Annual leave** | Minimum **21 calendar days** (art. 217), now counted in **calendar** (not working) days |
| **Seniority leave** | **+2 days** per **5 years** at one organization, capped at **+8 days** (art. 220) |
| **Rest** | Weekly rest days, holidays, paid annual leave guaranteed |
| **Working time** | Capped; reduced hours for certain categories |

## Practical takeaways for SMEs
- No verbal hiring — the contract must be written.
- State the probation period explicitly; never exceed 3 months.
- Draft the annual leave schedule at year start; under 21 days is a violation.
