# 🇺🇿 Rasmiy chiquvchi xat shabloni

## Foydalanish
O'zDSt 1157:2008 bo'yicha tashkiliy-farmoyish hujjatining rekvizitlari.
`[...]` — to'ldiriladigan maydonlar. Rekvizit yo'q bo'lsa, tashlab keting.

```
[TASHKILOT NOMI]
[Manzil, telefon, e-mail, veb-sayt]
[STIR / bank rekvizitlari — zarur bo'lsa]
______________________________________________________________

№ [chiquvchi raqam]                          [shahar], [KK.OO.YYYY]
[kiruvchi hujjatga javob bo'lsa: № ___ ga, [sana]]

                                             [Adresat: lavozimi]
                                             [Tashkilot nomi]
                                             [F.I.Sh. (Jo'nalish kelishigida)]

Hurmatli [ism-sharif]!

[1-xatboshi — murojaat maqsadi / sababi.]

[2-xatboshi — asosiy mazmun, dalillar, raqamlar.]

[3-xatboshi — aniq iltimos yoki taklif, muddat.]

Ilova: [nomi, varaqlar soni] — zarur bo'lsa.

Hurmat bilan,

[Lavozim]              _______________            [F.I.Sh.]
                          (imzo)                    [M.O'.]

Ijrochi: [F.I.Sh.], tel: [___]
```

## To'ldirish qoidalari
- **Chiquvchi raqam** chiquvchi hujjatlar jurnalidan ketma-ket beriladi.
- **Sana** — imzolangan kun.
- **Sarlavha** (matn mavzusi) uzun xatlarda tavsiya etiladi ("... to'g'risida").
- Bir xat — bir masala. Matn qisqa, aniq, rasmiy uslubda.
- Imzolovchi — hujjatni imzolashga vakolatli shaxs.

# 🇬🇧 Official Outgoing Business Letter Template

## Usage
Requisites of an organizational-administrative document per O'zDSt 1157:2008.
`[...]` are fill-in fields. Omit a requisite if not applicable.

```
[ORGANIZATION NAME]
[Address, phone, e-mail, website]
[Tax ID / bank details — if required]
______________________________________________________________

No. [outgoing number]                        [city], [DD.MM.YYYY]
[if a reply: In reply to No. ___ dated [date]]

                                             [Addressee: position]
                                             [Organization name]
                                             [Full name (dative case)]

Dear [name],

[Paragraph 1 — purpose / reason for writing.]

[Paragraph 2 — main content, arguments, figures.]

[Paragraph 3 — specific request or proposal, deadline.]

Enclosure: [title, number of pages] — if any.

Respectfully,

[Position]             _______________            [Full name]
                          (signature)               [Seal]

Prepared by: [Full name], tel: [___]
```

## Fill-in rules
- **Outgoing number** is assigned sequentially from the outgoing register.
- **Date** = the day it is signed.
- A subject/title line is recommended for long letters ("On ...").
- One letter — one matter. Keep the text short, precise, formal.
- The signer must be authorized to sign the document.
