# 🇺🇿 Ishdan bo'shatish buyrug'i — shablon

```
[TASHKILOT NOMI]

                              BUYRUQ

[sana] № [raqam]-k                                    [shahar]

Ishdan bo'shatish to'g'risida

[F.I.Sh.], [lavozim], [bo'lim] dan [KK.OO.YYYY] sanadan
[bo'shatish asosi] asosida ishdan bo'shatilsin.

Yakuniy hisob-kitob: [sana]gacha amalga oshirilsin.

Asos: [ariza / kelishuv / boshqa hujjat], [sana].

[Rahbar lavozimi]        ____________        [F.I.Sh.]
                            (imzo)   [M.O'.]

Buyruq bilan tanishdim:  ____________  [xodim F.I.Sh.], [sana]
                            (imzo)
```

## To'ldirish qoidalari
- Bo'shatish asosi HR-SOP-002 bosqich 1da hujjatlashtirilgan bo'lishi shart.
- Yakuniy hisob-kitob oxirgi ish kunida to'liq amalga oshirilishi kerak.
- Xodim buyruq bilan imzo qo'yib tanishishi shart.

# 🇬🇧 Termination Order — template

```
[ORGANIZATION NAME]

                              ORDER

[date] No. [number]-k                                 [city]

On termination of employment

[Full name], [position], [department] is terminated effective
[DD.MM.YYYY] on the basis of [grounds].

Final settlement: to be completed by [date].

Basis: [resignation letter / mutual agreement / other document], [date].

[Head's position]        ____________        [Full name]
                            (signature)  [Seal]

Acknowledged:            ____________  [employee name], [date]
                            (signature)
```

## Fill-in rules
- The grounds must already be documented per HR-SOP-002 step 1.
- Final settlement must be completed on the last working day.
- The employee must acknowledge the order by signature.
