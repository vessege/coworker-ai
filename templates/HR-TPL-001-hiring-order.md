# 🇺🇿 Ishga qabul qilish buyrug'i — shablon

```
[TASHKILOT NOMI]

                              BUYRUQ

[sana] № [raqam]-k                                    [shahar]

Ishga qabul qilish to'g'risida

[F.I.Sh.] [KK.OO.YYYY] dan [bo'lim nomi]ga [lavozim] lavozimiga
[oylik ish haqi: ___ so'm] bilan ishga qabul qilinsin.

[Sinov muddati: ___ oy — belgilangan bo'lsa.]

Asos: [sana]dagi № [___] mehnat shartnomasi; xodimning arizasi.

[Rahbar lavozimi]        ____________        [F.I.Sh.]
                            (imzo)   [M.O'.]

Buyruq bilan tanishdim:  ____________  [xodim F.I.Sh.], [sana]
                            (imzo)
```

## To'ldirish qoidalari
- Buyruq **shartnoma imzolangandan keyin**, uning shartlariga mos chiqariladi.
- Raqamga kadrlar indeksi qo'shiladi (masalan `15-k`).
- Xodim buyruq bilan **imzo qo'yib** tanishishi shart.
- Sinov muddati faqat shartnomada bo'lsa buyruqqa yoziladi.

# 🇬🇧 Hiring Order — template

```
[ORGANIZATION NAME]

                              ORDER

[date] No. [number]-k                                 [city]

On employment

Employ [Full name] as [position] in [department] from [DD.MM.YYYY]
with a monthly salary of [___ UZS].

[Probation period: ___ months — if set.]

Basis: employment contract No. [___] dated [date]; employee's application.

[Head's position]        ____________        [Full name]
                            (signature)  [Seal]

Acknowledged:            ____________  [employee name], [date]
                            (signature)
```

## Fill-in rules
- Issue the order **after** the contract is signed, matching its terms.
- Number carries the personnel index (e.g. `15-k`).
- The employee must acknowledge the order **by signature**.
- Probation appears in the order only if it is in the contract.
