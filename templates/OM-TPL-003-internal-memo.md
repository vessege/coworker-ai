# 🇺🇿 Ichki xizmat xati (eslatma) — shablon

```
[TASHKILOT NOMI]
[Bo'lim nomi]

                        ICHKI XIZMAT XATI

[sana]                                                № [raqam]

Kimga: [qabul qiluvchi lavozimi, F.I.Sh.]
Kimdan: [yuboruvchi lavozimi, F.I.Sh.]

Mavzu: [qisqa mavzu]

[Xat matni — muammo/taklif/so'rov qisqa va aniq bayon qilinadi.]

Ilova: [bo'lsa, hujjatlar ro'yxati]

[Lavozim]              ____________              [F.I.Sh.]
                          (imzo)
```

## To'ldirish qoidalari
- Mavzu bir jumlada aniq yozilishi kerak.
- Faqat bitta masalaga bag'ishlanadi — bir nechta masala uchun alohida xat.
- Ro'yxatga olish raqami OM-SOP-002 tartibida beriladi.

# 🇬🇧 Internal Memo — template

```
[ORGANIZATION NAME]
[Department name]

                        INTERNAL MEMO

[date]                                                No. [number]

To: [recipient's position, full name]
From: [sender's position, full name]

Subject: [short subject]

[Body — the issue/proposal/request stated briefly and clearly.]

Attachment: [document list, if any]

[Position]              ____________              [Full name]
                          (signature)
```

## Fill-in rules
- State the subject clearly in one line.
- Cover a single matter only — separate memos for separate matters.
- Registration number is assigned per OM-SOP-002.
