# 🇺🇿 Ish joyidan ma'lumotnoma — shablon

```
[TASHKILOT NOMI]
[Manzil, telefon, e-mail]

№ [chiquvchi raqam]                              [KK.OO.YYYY]

                        MA'LUMOTNOMA

Ushbu ma'lumotnoma [F.I.Sh.]ga berildi. U haqiqatan ham
[tashkilot nomi]da [KK.OO.YYYY]dan buyon [lavozim] lavozimida
ishlab kelmoqda.

[Ixtiyoriy: Oylik ish haqi: [summa] so'm.]

Ma'lumotnoma [taqdim etiladigan joy: bank / elchixona / talab
qilingan joyga] taqdim etish uchun berildi.

[Rahbar lavozimi]      ____________      [F.I.Sh.]
                          (imzo)   [M.O'.]
```

## To'ldirish qoidalari
- Chiquvchi raqam jurnaldan beriladi (OM-SOP-002).
- Ish haqi faqat xodim roziligida/so'rovda ko'rsatiladi.
- "Talab qilingan joyga" — universal variant.
- Imzo + muhr shart, aks holda ko'p tashkilot qabul qilmaydi.

# 🇬🇧 Employment Certificate (Ma'lumotnoma) — template

```
[ORGANIZATION NAME]
[Address, phone, e-mail]

No. [outgoing number]                            [DD.MM.YYYY]

                        CERTIFICATE

This is to certify that [Full name] has been employed by
[organization name] as [position] since [DD.MM.YYYY].

[Optional: Monthly salary: [amount] UZS.]

Issued for presentation to [bank / embassy / whom it may concern].

[Head's position]      ____________      [Full name]
                          (signature)  [Seal]
```

## Fill-in rules
- Outgoing number comes from the register (OM-SOP-002).
- Include salary only with the employee's consent/request.
- "To whom it may concern" is the universal variant.
- Signature + seal required — many institutions reject it otherwise.
